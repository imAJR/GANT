# GANT — محاكي تخطيط المشروعات

تطبيق تعليمي تفاعلي باللغة العربية يحاكي مساحة عمل لتخطيط المشروعات باستخدام مخطط جانت، ومصمم لدعم **التقنية الرقمية 3 — الوحدة الأولى: تخطيط المشروعات**.

## ما الذي يقدمه؟

- جدول مهام ومخطط جانت متزامنان.
- خصائص المشروع والتقويم وأيام العطلة.
- تنظيم المهام الهرمي والمهام التلخيصية والمعالم الرئيسية.
- علاقات الاعتمادية بين المهام.
- الموارد والأدوار وتخصيص الموارد للمهام.
- حفظ حالة المشروع وسجل التراجع/الإعادة واستيراد/تصدير بيانات المشروع.
- تدريب إرشادي من 10 خطوات مع المساعد التعليمي «نحلة جانت» والتحقق من إنجاز الطالب.

## المتطلبات

- Node.js 22 أو إصدار متوافق مع إصدار Vite المستخدم.
- npm.

## التشغيل محليًا

```bash
npm install
npm run dev
```

يفتح Vite خادم التطوير على المنفذ `3000` بحسب إعدادات المشروع.

## أوامر التحقق

```bash
npm run lint
npm test
npm run build
```

- `npm run lint`: فحص TypeScript.
- `npm test`: اختبارات شروط الخطوات التعليمية العشر، والتقويم وأيام العمل والاعتمادية بين المهام.
- `npm run build`: إنشاء نسخة الإنتاج داخل مجلد `dist`.

يُشغّل GitHub Actions هذه الفحوص عند الدفع إلى المستودع أو فتح طلب دمج.

## إعداد ميزات الذكاء الاصطناعي

يحتوي الملف `.env.example` على أسماء متغيرات نموذجية. إذا كانت إحدى ميزات Gemini تتطلب مفتاح API، أنشئ ملف `.env.local` محليًا وضع المفتاح فيه حسب إعدادات البيئة المستخدمة. **لا ترفع مفاتيح API أو أسرارًا حقيقية إلى GitHub.** قد تختلف طريقة توفير المتغيرات عند النشر حسب منصة الاستضافة.

## هيكل المشروع

- `src/components/`: واجهات التطبيق، ومخطط جانت، والجدول، والنوافذ والمساعد.
- `src/context/ProjectContext.tsx`: حالة المشروع وعمليات التعديل.
- `src/data/initialProject.ts`: بيانات البداية وسيناريو التدريب.
- `src/data/tutorialSteps.ts`: الخطوات التعليمية وشروط التحقق.
- `src/utils/calendar.ts` و`src/utils/scheduler.ts`: التقويم وحساب الجدولة.
- `tests/tutorialSteps.test.ts`: اختبارات شروط الخطوات التعليمية.
- `tests/scheduler.test.ts`: اختبارات التقويم وحساب النهايات وترحيل المهام التابعة ومنع دورات الاعتمادية.

## ملاحظات

- نجاح البناء واختبارات التحقق لا يغني عن اختبار واجهة التطبيق يدويًا في المتصفح وعلى أحجام الشاشات المستهدفة.
- لم تُضبط منصة نشر عامة ضمن هذا المستودع؛ يجب إعداد الاستضافة ومتغيرات البيئة واختبار النسخة المنشورة قبل مشاركة رابط نهائي.
